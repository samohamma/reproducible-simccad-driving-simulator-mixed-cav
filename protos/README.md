# `protos/`

This folder contains Webots PROTO definitions and related assets used by the generated worlds.

## Main subfolders

| Folder | Purpose |
|---|---|
| `abstract/` | Shared/abstract vehicle and component PROTO resources. |
| `bmw/` | BMW vehicle PROTO and assets for automated vehicles. |
| `bmwAU/` | Australian/interior variant of the BMW vehicle used for the participant/ego vehicle. |

These files are required for Webots to load the generated worlds correctly.
