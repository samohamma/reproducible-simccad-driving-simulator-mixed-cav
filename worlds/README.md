# `worlds/`

This folder contains Webots world files.

## Main files

| File pattern | Meaning |
|---|---|
| `ExperimentDesign.wbt` | Baseline generated experiment world. |
| `bench_cavs10.wbt` ... `bench_cavs39.wbt` | Benchmark variants generated by `main.py`; only the number of surrounding CAVs is varied. |
| `.bench_cavsXX.wbproj` | Hidden Webots view/project-state files. These are not the core reproducibility artefacts. |

## Regeneration

Benchmark worlds can be regenerated from the project root:

```bash
python main.py --benchmark-generate-only
```

A full generate-and-benchmark run is:

```bash
python main.py --benchmark --mode run
```

Avoid manually editing benchmark `.wbt` worlds unless you are intentionally creating a fixed experimental snapshot.
