# `controllers/auto_broken/`

Controller for the broken/takeover-triggering vehicle.

## Role

- Controls the vehicle used to create the broken-vehicle/takeover condition.
- Reads traffic-light/trigger information and controller parameters.
- Contributes to the event structure of the mixed-CAV experiment.

This controller should remain aligned with the traffic-light naming convention generated by `GenereateExperiment/lights.py`.
