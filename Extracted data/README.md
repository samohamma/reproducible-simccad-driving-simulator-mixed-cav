# `Extracted data/`

This folder stores data generated during experiment or benchmark execution.

It is not used to generate Webots worlds, but it is part of the reproducibility record because it stores runtime outputs from controllers and benchmark evaluation.

## Subfolders

| Folder | Purpose |
|---|---|
| `Participant/` | Participant/ego vehicle runtime data from experiment runs. |
| `SimCCAD_CAVs/` | Automated CAV runtime data from controller logs. |
| `performance/` | Benchmark real-time-factor outputs and generated figures. |

The current benchmark demonstration uses `Extracted data/performance/` as the main output folder.
