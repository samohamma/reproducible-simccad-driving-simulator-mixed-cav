# `Extracted data/Participant/`

This folder contains participant/ego-vehicle runtime logs from experiment runs.

Typical filenames follow:

```text
Run-Data-YYYYMMDD-Time-HHMMSS-PT.csv
```

These files record ego/participant vehicle state and interaction variables such as simulation time, position, speed, driving mode, indicator/brake/pedal inputs, and experiment messages.

These files are retained as runtime records. They are not required for regenerating benchmark worlds.
