# `Extracted data/SimCCAD_CAVs/`

This folder contains runtime logs from automated CAV controllers.

Typical filenames follow:

```text
Run-Data-YYYYMMDD-Time-HHMMSS-CAV.csv
```

These logs record automated vehicle states during simulation. They are retained as runtime records and are separate from the benchmark real-time-factor outputs in `Extracted data/performance/`.
